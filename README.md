# 🧾 Log Collector Server

A scalable log ingestion and analysis system designed to collect, store, and visualize logs from multiple services in real-time.

---

## 🚀 Overview

The Log Collector Server solves a key problem in distributed systems:  
**tracking, searching, and analyzing logs across multiple services efficiently.**

Instead of manually checking logs from different services, this system:
- Centralizes logs
- Indexes them for fast search
- Provides a dashboard for insights

---

## ✨ Features

- 📥 Centralized log ingestion from multiple services  
- ⚡ High-performance search using GIN indexing  
- 🔎 Full-text search on large log messages  
- 📊 Interactive dashboard with analytics  
- 🧵 Request tracing using `request_id`  
- 🛠️ REST API for log submission and querying  
- 🐳 Docker support for deployment
